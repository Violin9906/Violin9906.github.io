# Résumé

## 个人简介

我是中国科学技术大学的研究助理，师从吉建民副教授。凭借在控制理论和知识表示领域打下的扎实基础，我的研究方向正从基于逻辑的自动驾驶安全评估，转向先进无人机控制以及连续体软体机器人与无人机的协同控制。
我致力于将形式化推理与敏捷物理控制相结合，以提升复杂自主机器人系统的安全性与通用性。

## 个人亮点

- 自动驾驶安全评估：具备基于场景的自动驾驶安全评估方法研究经验。
- 规划算法与强化学习：熟悉自动驾驶规划算法，并对强化学习有一定了解。
- 逻辑编程专长：精通基于回答集编程（Answer Set Programming, ASP）的逻辑编程。
- 机器人综合素养：掌握控制理论、电路理论、嵌入式系统开发以及机器人硬件设计和物理建模等专业知识。
- 软件与工具链：熟练使用 C/C++、Python、ROS/ROS 2 以及 MATLAB & Simulink。
